# Painel Prova Paulista — 3º Bimestre (URE)

Painel web estático (HTML + CSS + JS, sem dependências) com filtros, ranking por impacto do déficit e mapa de calor.

## Publicar no GitHub Pages
1. Crie um repositório e envie `index.html` e este `README.md`.
2. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Atualizar os dados
Os dados ficam na constante `D` dentro de `index.html`. Substitua o JSON pelos novos resultados (mesma estrutura).

> Atenção: os dados são por escola. Use repositório privado ou confirme se a divulgação é permitida.
